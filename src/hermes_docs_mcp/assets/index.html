hermes-docs

MCP-коннектор к официальной документации Hermes Agent: ассистент сам ищет ответ в доке и ссылается на страницу.

Адрес для подключения — вставьте его в «Add custom connector»:

https://hermes-docs-mcp.onrender.com/mcp
Транспорт
Streamable HTTP
Авторизация
нет, доступ открытый
Инструменты
search(query) и fetch(id)

Документация англоязычная, поиск лексический — запрос стоит формулировать по-английски, отвечать вам ассистент может по-русски.

Исходный код и условия — github.com/shi-kirill/hermes-docs-mcp. Проект неофициальный; документация принадлежит Nous Research.
